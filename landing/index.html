FAQ

要装 AutoCAD 吗？
不要。图译是独立桌面程序。DXF 直接读；DWG 用你本机的 ODA File Converter。
ODA 打进安装包了吗？
没有，也不会。协议不允许跟软件一起发。你自己在电脑上装 ODA File Converter 就行；只译 DXF 可以先不装。
第一次打不开？
正常。Mac 右键图标，选打开。Windows 点更多信息，再点仍要运行。Windows 要 10 或 11 的 64 位。Mac 现在只有 Apple 芯片（M1 及以后）；Intel 要另打一份，还没上。
收费吗？有授权码吗？
没有。MIT 开源，无试用、无收款码。翻译要用的密钥是你自己的 Azure / DeepL / Ollama / 自定义接口。想改代码就提 PR，合进 main 前我会看。
