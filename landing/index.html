常见问题

Windows 哪个版本能用？
Windows 10 或 11，64 位。32 位不行，Windows 7 / 8 不行。Win10 如果提示缺少 WebView2，装微软的 Edge WebView2 运行时。
我的 Mac 该下哪一份？
左上角苹果 → 关于本机。写着「Apple M1 / M2 / M3 / M4」就下 Apple 芯片。写着 Intel 就下 Intel。两份不能混。Intel 包还没打出来时，按钮会告诉你。
要装 AutoCAD 吗？
不要。图译是独立程序。DXF 直接读；DWG 用你本机的 ODA File Converter。
ODA 打进安装包了吗？
没有，也不会。协议不允许跟软件一起发。你自己装 ODA File Converter。只译 DXF 可以先不装。
第一次打不开？
正常，安装包还没买代码签名。Mac：右键图标，选打开。Windows：更多信息 → 仍要运行。
收费吗？有授权码吗？
没有。MIT 开源。翻译用的密钥是你自己的 DeepL / Azure / Ollama / 自定义接口。图译不建账号，默认也不往外打电话，除非你点检查更新。
