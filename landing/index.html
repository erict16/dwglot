FAQ

要装 AutoCAD 吗？
不要。图译是独立桌面程序。DXF 直接读；DWG 用你本机的 ODA File Converter。
ODA 打进安装包了吗？
没有，也不会。Community 协议不允许随应用分发。设 CAD_ODA_EXEC 或按系统路径检测。
为什么 Gatekeeper / SmartScreen 拦我？
v0.1 未签名。Mac 用右键打开；Windows 点仍要运行。这是预期行为，写在 README 安装里。
收费吗？有授权码吗？
没有。MIT，无试用、无收款码。引擎密钥是你自己的 Azure / DeepL / Ollama / 自定义 API。
