短答

就这 几句。

要装 AutoCAD 吗？

不要。图译是独立程序。DXF 直接读；DWG 用你本机的 ODA File Converter。

ODA 打进安装包了吗？

没有，也不会。协议不允许跟软件一起发。只译 DXF 可以先不装。

Windows 哪个版本能用？

Windows 10 或 11，64 位。32 位不行，7 / 8 不行。Win10 缺 WebView2 就装微软那个运行时。

我的 Mac 该下哪一份？

苹果菜单 → 关于本机。写着 M1 / M2 / M3 / M4 就下 Apple 芯片。写着 Intel 就下 Intel。两份不能混。

第一次打不开？

正常，安装包还没买代码签名。Mac：右键图标 → 打开。Windows：更多信息 → 仍要运行。

收费吗？有授权码吗？

没有。MIT。翻译密钥是你自己的 DeepL / Azure / Ollama / 自定义接口。图译不建账号。
